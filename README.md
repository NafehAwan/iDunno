# For Mam Saba 🌸

A cute, animated farewell website — a surprise goodbye gift.

It's a single static `index.html` (all styles + scripts are inline, fonts load
from Google Fonts). No build step, no dependencies.

## Deploy to Vercel

### Option A — Import from GitHub (easiest)
1. Go to **https://vercel.com/new**
2. Import this repository (`NafehAwan/RacePLugin`).
3. **Framework Preset:** leave as **Other**.
4. Leave **Build Command** and **Output Directory** empty.
5. Click **Deploy**. Done — you'll get a live link like `your-project.vercel.app`.

### Option B — Vercel CLI
```bash
npm i -g vercel
vercel        # follow the prompts (accept the defaults)
vercel --prod # publish to your production URL
```

## Run locally
Just open `index.html` in any browser (double-click it), or:
```bash
npx serve .
```
